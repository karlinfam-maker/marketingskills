# Маркетинговые навыки — оглавление на русском

Это справочник к набору [Marketing Skills](README.md) от Corey Haines. Английские названия сохранены: по ним можно открыть и установить конкретный навык. Описание помогает выбрать инструмент; установка здесь не выполняется. Часть навыков ориентирована на IT-продукты и digital-маркетинг, поэтому для других отраслей может потребоваться адаптация.

## Как пользоваться

1. Найдите задачу в таблице и откройте название навыка: ссылка ведёт в его папку.
2. Перед установкой проверьте инструкции и, при наличии, дополнительные файлы и скрипты.
3. Установите выбранный навык для нужной среды отдельно. Сохранение репозитория не означает установку.
4. Сформулируйте задачу по-русски и укажите название навыка; поддержка явного вызова зависит от среды.

Оригинальные инструкции и условия использования: [README.md](README.md) и [LICENSE](LICENSE). Это оглавление отражает список навыков на момент создания и не обновляется автоматически.
